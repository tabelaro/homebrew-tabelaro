# Homebrew tap for Tabelaro

[Tabelaro](https://tabelaro.com) is a free macOS database client for PostgreSQL, MySQL/MariaDB and SQLite.

```sh
brew install --cask tabelaro/tabelaro/tabelaro
```

Or tap it first:

```sh
brew tap tabelaro/tabelaro
brew install --cask tabelaro
```

To update, run `brew reinstall --cask tabelaro`, which downloads the latest build.

Tabelaro is not signed or notarized, so this cask removes the macOS quarantine flag after installing.

Questions: feedback@tabelaro.com
